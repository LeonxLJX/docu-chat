Frequently asked

A few honest answers before you buy.

Wait — I pay $49, then what else do I pay?
That's it for Docu-Chat. You pay your own Railway hosting (~$5/mo, has free tier) and your own OpenAI API usage (typically $5–$15/mo for a small shop, less than a latte). No per-seat fees, no per-message markup, no renewal.
Will this work with my docs as-is?
PDF, DOCX, Markdown, TXT, CSV, JSON all work out of the box. Drop them in, wait ~2 minutes per document, and they're searchable. You don't need to reformat anything.
How long does setup actually take?
If you've used Railway before — 5 minutes. Clone, deploy from GitHub, set 3 env vars, mount a volume. If not — 15 minutes following the README. The hard part is writing good docs, not wiring up the bot.
What happens when the bot doesn't know the answer?
Two safety nets: (1) We instruct the model to say "I don't know" instead of hallucinating (you can edit the system prompt). (2) Buyers can click "Talk to a human" or type it in chat — a ticket appears in your dashboard instantly.
Is my data safe?
Yes. Your docs are chunked and stored as embeddings in your own SQLite file, which lives on your Railway volume. Your OpenAI API key is stored in that same SQLite file and the dashboard returns a masked version. We never see either, we don't even have servers to route through.
Can I use a cheaper LLM instead of OpenAI?
Yes. The `openai` SDK honors `OPENAI_BASE_URL`, so you can point it at Together, Groq, OpenRouter, or any OpenAI-compatible endpoint. Change `chat_model` in Settings to whatever model your provider exposes.
What's the catch with self-hosting?
One thing: your SQLite file lives on a persistent disk. If Railway wipes the volume (rare), your knowledge base goes with it. We recommend a nightly `cp /data/docuchat.db /data/backup.db` — that's one cron line. Railway also does nightly volume snapshots.
